# 王者荣耀排位模拟器

一款基于 Phaser 3 + Vite 构建的 H5 排位模拟器小游戏。玩家需要在限定天数内从青铜冲上王者段位，合理分配每日时间、管理资源和心态，最终成为最强召唤师。

## 玩法简介

### 目标与结束条件

- **胜利**：在限定天数内段位晋升至 👑 王者
- **失败**：精力归零 / 心态崩溃 / 沉迷度满 100 / 天数用完未达王者

### 五大核心资源

| 资源 | 范围 | 说明 |
|------|------|------|
| ⚡ 精力 | 0~100 | 身体状态，归零则游戏结束 |
| 🎯 技术 | 0~200 | 游戏水平，直接影响排位胜率 |
| 😊 心态 | 0~100 | 精神状态，归零则游戏结束 |
| 💰 金币 | 0~9999 | 货币，用于商店购买和训练消耗 |
| 📱 沉迷度 | 0~100 | 满 100 则游戏结束 |

### 时间与透支

- 每天 **10 小时**基础行动时间，可透支到最多 24 小时
- 透支为**即时惩罚**（每次透支行动时立即扣除），不存在隔夜惩罚：

| 透支时长 | 每次行动惩罚 |
|---------|-------------|
| 1~2h | 精力-3 技术-1 |
| 3~5h | 精力-5 技术-2 |
| ≥6h | 精力-8 技术-3 心态-5 |

- 未透支 → 隔天恢复精力+15 心态+5
- 透支过 → 无隔天恢复

### 七种行动

| 行动 | 耗时 | 效果 | 解锁 |
|------|------|------|------|
| 🏆 排位 | 3h | 胜→升段+金币；败→掉段+心态损失 | 初始 |
| 🎯 训练 | 2h | 技术+5~12，花费 15 金；15%顿悟额外技术 | 初始 |
| 📺 观赛 | 2h | 技术+3~7，沉迷+5~10 | 初始 |
| 💼 代练 | 2h | 金币+40~65，沉迷+8~13 | 初始 |
| 🎮 匹配 | 1h | 技术+3~5，心态+3 | 白银解锁 |
| ☕ 小憩 | 1h | 精力+10~17，心态+5~9，沉迷-5~8 | 初始 |
| 🛒 商店 | 0h | 花金币购买道具即时生效 | 初始 |

### 段位体系

青铜III → 青铜II → 青铜I → 白银III → … → 星耀I → 👑 王者（共 19 个小段）

排位胜率由技术值、心态、英雄加成、天赋、好友、连胜/连败、难度综合决定，范围 10%~88%。

连胜≥3 额外胜率加成 | 连胜≥2 额外金币奖励 | 连败≥3 触发保护（50%不掉段）

## 系统玩法

### 英雄系统（6 个）

| 英雄 | 费用 | 特殊效果 |
|------|------|---------|
| ⚔️ 战士 | 免费 | 排位胜率+3% |
| 🗡️ 刺客 | 60 金 | 训练效率+25%，精力消耗+10% |
| 🔮 法师 | 60 金 | 技术成长+20%，心态恢复-15% |
| 🛡️ 坦克 | 80 金 | 精力消耗-20%，技术成长-10% |
| 🏹 射手 | 80 金 | 金币收入+30%，沉迷增加+15% |
| 💚 辅助 | 100 金 | 心态恢复+30%，技术成长-15% |

### 天赋系统（5 阶段，每阶段 3 选 1）

| 解锁段位 | 选项 |
|---------|------|
| 白银 | 🦉 夜猫子（透支惩罚-30%）/ 📚 速成天才（训练+20%）/ 🛡️ 厚脸皮（败心态-25%） |
| 黄金 | 💪 钢铁意志（精力消耗-15%）/ 🤑 招财进宝（金币+25%）/ 🧘 心态大师（小憩心态+40%） |
| 铂金 | 🎯 关键先生（胜率+5%）/ ⚡ 效率达人（行动耗时-1h）/ ❤️ 恢复体质（每日精力+10） |
| 钻石 | 👑 Carry之王（胜率+8%）/ 🧠 防沉迷大师（沉迷-30%）/ 🎰 孤注一掷（奖励+40%/惩罚+20%） |
| 星耀 | 🚀 最后冲刺（所有属性+15%）/ 🍀 幸运之星（事件好选项+50%）/ 🏃 持久作战（每日+2h） |

### 好友系统

- 每次行动后 12% 概率遇到新好友（共 15 位）
- 可设为双排伙伴，在排位中提供胜率/技术/心态/金币加成
- 每位好友有独特性格和对话

### 商店系统（6 大分类，52+ 件商品）

🍔 食物饮品 | 💊 恢复补给 | 📚 学习资料 | 🎭 娱乐休闲 | 🧘 心态调整 | 🎁 稀有礼包

包含峡谷刮刮乐（头奖 0.5% 金币+400，最高至 65% 未中奖）

### 每日任务（37 个任务池，每天随机 3 个）

覆盖排位/训练/休息/观赛/代练/匹配/商店/综合挑战，完成即时获得奖励。

### 成就系统（15 个）

初露锋芒 / 三连胜 / 五连胜 / 各段位成就 / 小富翁 / 技术大师 / 完美一天 / 绝处逢生 / 购物狂 / 夜猫子 / 心如止水

### 随机事件（25 个）

每次行动后 40% 概率触发，按行动类型分类：排位 6 个 / 训练 4 个 / 观赛 4 个 / 休息 4 个 / 匹配 4 个 / 代练 4 个 / 通用 8 个。事件选项包括技术判定对决、花钱购买、闪避判定等。

### 难度选择

| 参数 | 🌱 简单 | 🔥 困难（默认） | 💀 职业 |
|------|---------|---------------|---------|
| 天数上限 | 40 天 | 30 天 | 22 天 |
| 初始金币 | 80 | 50 | 30 |
| 胜率加成 | +6% | 0 | -5% |
| 金币/技术/精力/心态/沉迷倍率 | 宽松 | 标准 | 严苛 |

### 存档系统

- **自动存档**：每天睡觉时自动保存
- **手动存档**：3 个手动存档槽
- 支持加载、覆盖、删除

### 其他特性

- 每日智能提示：根据状态自动生成建议和警告
- 分类日志系统：系统/行动/数值/段位/任务/解锁/商店/事件/存档，带彩色标签
- 自适应布局，支持多种屏幕尺寸

## 技术栈

- **Phaser 3** — 游戏引擎（场景管理）
- **Vite** — 构建工具
- **HTML/CSS DOM** — 全 UI 层（状态栏、行动面板、弹窗、商店）
- **localStorage** — 存档系统

## 快速开始

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:17500` 即可游玩。

## 构建部署

```bash
npm run build
```

生成的静态文件在 `dist/` 目录，可部署到任何静态服务器。

## 项目结构

```
src/
├── scenes/          # Phaser 场景（BootScene、MenuScene、GameScene）
├── systems/         # 核心系统（PlayerManager、ActionSystem、EventSystem、GameManager、SaveManager）
├── ui/              # DOM UI 组件（GameUI、EventModal、ShopModal）
├── data/            # 游戏数据（段位、事件、商店、英雄、天赋、成就、任务、好友、难度）
└── styles/          # CSS 样式
```
